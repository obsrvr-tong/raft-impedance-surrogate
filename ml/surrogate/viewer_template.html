About the model

How it works

Each term is split into its static value and a dimensionless shape, K(f) = Kstatic × shape(f). The logarithm of the static value and 20 principal-component weights of the shapes are each predicted by a Gaussian process (Matérn 5/2 kernel, one length scale per input) on top of a linear trend in the inputs: 28 GPs in all. The training set includes every raft turned by 90°, which on layered soil is the same physical case.

The band combines two sources: the uncertainty of the GPs, each computed from its nearest training cases (which can only overstate it), and the detail the 20 principal components leave out, measured on the training curves. Most of the remaining error is that second part.
